Pocket Bookmark Manager Extension Privacy Policy

Last Updated: 18/05/2024

1. Data Collection & Usage

This extension helps users manage browser bookmarks efficiently with encrypted data handling:

  • Bookmark Data: Integrated with our cloud-based bookmark system where data is primarily stored on secure servers, with partial caching locally for performance. All operations are synchronized between the browser and our cloud system.
  • Account Credentials: Stored encrypted, visible only to the account owner
  • Sharing Feature: Users can optionally share specific bookmarks without granting edit permissions

2. Permission Justifications

tabs Permission

Gets current page URL for one-click bookmarking

storage Permission

Stores user's bookmark categories and settings locally to enhance performance and user experience, while all primary data remains securely stored on cloud servers. Specifically:​​ ​Local Caching: Temporarily stores frequently accessed data (e.g., bookmark categories, UI preferences) for instant loading. ​Cloud Sync: All critical data is securely synchronized with our cloud servers (HTTPS encrypted) to ensure reliability. ​User Control: Users can clear local storage anytime via extension settings.

scripting Permission

Dynamically executes scripts to interact with browser bookmark system for:

  • Reading/modifying bookmark data (add/delete/update)
  • Automating bookmark management actions
  • Bookmark group management and batch operations
  • Searching and filtering functionality

contextMenus Permission

Adds right-click menu option to save current page as bookmark

sidePanel Permission

Provides quick-access bookmark sidebar

Host Permission

Accesses and manages user's bookmark data locally

3. Remote Code Usage

To ensure compatibility with PC bookmark systems, this extension uses remote code:

  • Loaded securely via HTTPS from trusted domain (https://navfinder.cn/)
  • Synchronizes bookmark categories and permission rules
  • Adapts dynamically to backend API changes
  • Offloads complex operations to remote Wasm modules for performance

4. Data Security

All user data is encrypted with exclusive access:

  • Only the owner can view their bookmarks
  • Modification and deletion restricted to owner
  • Optional sharing of specific bookmarks under user control
